# AhmedNoorim.github.io

My academic homepage, served by GitHub Pages at **https://ahmednoorim.github.io**.

It's plain HTML, CSS, and JavaScript. There's no build step and no framework, so you edit the files and push.

## Files

```
index.html              Everything on the page.
css/style.css           Layout, colors, fonts, and the light/dark theme
js/theme.js             Sets the saved light or dark theme before the page loads
js/main.js              Contents panel, section highlighting, mobile menus, theme toggle
assets/img/profile.jpg  Profile photo
assets/img/favicon.svg  Tab icon
files/                  Ahmed_Noorim_CV.pdf here for the "Download CV" button
.nojekyll               Tells GitHub Pages to serve the files as they are
```
